# S.S.W Intelligence System

Plataforma de auditoria web e análise de performance digital.

## Sobre

Sistema para análise e avaliação de sites, fornecendo insights sobre performance, acessibilidade e experiência do usuário.

## Funcionalidades

- Auditoria de sites
- Análise comparativa
- Geração de relatórios
- Sistema de autenticação

## Como Usar

### Requisitos
- Navegador web moderno
- Conexão com internet

### Instalação
```bash
# Clone o repositório
git clone https://github.com/GuilhermeCCS/ssw-intelligence-system.git
cd ssw-intelligence-system

# Instale dependências
npm install

# Inicie o servidor
npm start
```

### Acesso
Após iniciar o servidor, acesse via navegador no endereço indicado no terminal.

## Tecnologias Utilizadas

- HTML5, CSS3, JavaScript
- TailwindCSS
- Lucide Icons

## Design System

Interface moderna com tema dark, responsiva e otimizada para diferentes dispositivos.

## Arquitetura

Aplicação web estática com arquitetura client-side, focada em performance e experiência do usuário.
